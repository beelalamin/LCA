# LC Assets — Luxury Code Asset Management

> Internal IT asset lifecycle management system built with **FilamentPHP 3.x** and **Laravel 11**.

---

## Tech Stack

| Layer             | Technology                         |
|-------------------|------------------------------------|
| Backend + Frontend| FilamentPHP 3.x on Laravel 11      |
| Database          | SQLite / MySQL / PostgreSQL       |
| Auth & Roles      | Laravel Sanctum + Filament Shield  |
| i18n              | English & Arabic (RTL)             |
| Charts            | Filament ApexCharts                |
| PDF Export        | barryvdh/laravel-dompdf            |
| Bulk Import       | maatwebsite/excel                  |
| Barcode / QR      | milon/barcode + endroid/qr-code    |
| Settings          | spatie/laravel-settings            |

## Prerequisites

- **PHP** ≥ 8.3 (available via [Laravel Herd](https://herd.laravel.com) or standalone)
- **Composer** ≥ 2.x (bundled with Herd)
- **Node.js** ≥ 18 & npm (for frontend assets)

## Project Setup

### 1. Clone the repository

```bash
git clone <repository-url> LCA
cd LCA
```

### 2. Install PHP dependencies

```bash
composer install
```

### 3. Configure environment

```bash
cp .env.example .env
php artisan key:generate
```

### 4. Create the database

#### Option A: SQLite (Default)
```bash
touch database/database.sqlite
```

#### Option B: MySQL
1. Create a database in MySQL (e.g., `lc_assets`).
2. Update `.env`:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=lc_assets
   DB_USERNAME=your_username
   DB_PASSWORD=your_password
   ```

> **Note:** The permission tables migration has been updated to support UUIDs (`model_id`) for compatibility with our User model.

### 5. Run migrations with seed data

```bash
php artisan migrate --seed
```

This creates all tables and seeds demo data including:
- 1 admin user (`admin@lca.local` / `password123`)
- 4 categories (Laptops, Desktops, Monitors, Printers)
- 3 employees
- 4 assets with assignments and maintenance logs

### 6. Create the super admin user & assign role

Run the following command to create the initial admin and assign the `super_admin` role:

```bash
php artisan tinker --execute="
\$user = \App\Models\User::firstOrCreate(
    ['email' => 'admin@luxurycode.qa'],
    [
        'full_name' => 'Super Admin',
        'password' => \Illuminate\Support\Facades\Hash::make('password123'),
        'role' => 'admin',
        'is_active' => true,
        'preferred_locale' => 'en',
    ]
);
\$role = \Spatie\Permission\Models\Role::firstOrCreate(['name' => 'super_admin', 'guard_name' => 'web']);
\$user->assignRole('super_admin');
echo '✅ Super Admin created and role assigned: ' . \$user->email;
"
```

### 7. Initialize Filament Shield (roles & permissions)

Generate all permissions and policies for the resources:

```bash
php artisan shield:generate --all
```

When prompted, select the **admin** panel.

### 9. Install frontend dependencies & build

```bash
npm install
npm run build
```

### 10. Start the development server

```bash
php artisan serve
```

Or use the built-in `composer dev` script (starts server, queue, logs, and Vite concurrently):

```bash
composer dev
```

## Project Structure

```
app/
├── Enums/              # AssetStatus, ConditionRating, etc.
├── Filament/
│   ├── Pages/          # Dashboard
│   ├── Resources/      # Asset, Category, Employee, User, etc.
│   └── Widgets/        # Stats & Chart widgets
├── Models/             # Eloquent models (UUID-based)
├── Observers/          # Asset & Assignment observers
├── Policies/           # Auto-generated by Filament Shield
├── Providers/          # App & Filament panel providers
└── Services/           # Business logic services
database/
├── factories/          # Model factories
├── migrations/         # Schema migrations
└── seeders/            # DatabaseSeeder with demo data
```
